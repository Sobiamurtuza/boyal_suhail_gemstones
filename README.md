## Publish free using GitHub Pages
1. Sign in at https://github.com/
2. Create a **public** repository named `muhammad-suhail-emerald-portfolio` (or another name).
3. Upload both `index.html` and `muhammad-suhail.jpg` to the repository root.
4. Open **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-USERNAME.github.io/muhammad-suhail-emerald-portfolio/`

Alternative free hosts: https://app.netlify.com/ or https://pages.cloudflare.com/
